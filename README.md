# Simple Legal Assistant India 🏛️

The **simplest possible** legal assistant using just HTML, CSS, and JavaScript.

![App Screenshot](./screenshot.jpg)

## Tech Stack (Super Simple!)
- **HTML**: Structure and content
- **CSS**: Styling and layout  
- **JavaScript**: Logic and API calls
- **Gemini AI**: Legal analysis

## Why This Tech Stack?
✅ **Easy to learn** - Just basic web technologies  
✅ **Easy to explain** - No complex frameworks  
✅ **Works everywhere** - Any browser, any server  
✅ **No build process** - Just open the HTML file  
✅ **Interview friendly** - Demonstrates core web skills  

## Setup (3 Simple Steps)

1. **Download the files**
2. **Open `index.html` in your browser**
3. **Paste your Gemini API key** in the "Gemini API Key" box at the top and click **Save**

That's it! No installation, no build process, no complex setup.

## Features
- 🌍 Multi-language support (10+ Indian languages)
- 🔍 Auto language detection
- ⚖️ IPC sections and legal analysis
- 📱 Mobile responsive
- 🚀 Fast and lightweight
